# Changelog

## 0.3.0 — first public release

- English and Russian localization, language picker in Settings → General.
- Modules: every feature can be turned off and disappears from the menu and settings.
- Standing desk mode: posture switches as breaks, confirmed with one click; standing time in statistics.
- Calendar: take the break early before meetings; optionally treat meetings as calls.
- Quiet mode and Focus: gentle corner-card breaks; `blinky://` URL scheme for Shortcuts automations.
- Screen sharing / recording detection.
- Weekly statistics with a good-day streak.
- Eye exercises on long breaks; wallpaper or custom image background; start/end sounds; Shortcuts at start/end.
- Global hotkeys ⌃⌥⌘B / P / S / M / Q / U.
- Pause music during breaks (off by default).
- Universal binary (Apple Silicon + Intel), app icon.

## 0.1.0 — MVP

- Short and long breaks, heads-up, snooze limit, strict mode.
- Blink and posture reminders.
- Smart pause: per-process microphone, camera, video, full-screen games, focus apps, idle.
- Working hours, menu bar status, daily statistics.
